1.1 Por que async?

O projeto faz muito I/O bloqueante (banco + API Bling). Com async, enquanto uma requisição espera o Bling responder (até 60 s em criar_nf), o servidor atende outras.

# ERRADO — bloqueia o event loop inteiro
import time, requests
def emitir():
    time.sleep(5)
    requests.post(...)

# CERTO — libera o loop (padrão do seu projeto)
import asyncio, httpx
async def emitir():
    await asyncio.sleep(5)
    async with httpx.AsyncClient() as c:
        await c.post(...)
Atenção

Nunca use requests, time.sleep ou driver síncrono (psycopg2) dentro de uma rota async def. Um único bloqueio congela todas as requisições do worker.

1.4 O arquivo .env

LGPD / Segurança

.env nunca vai para o Git. Adicione ao .gitignore antes do primeiro commit.

DATABASE_URL=postgresql+asyncpg://usuario:senha@localhost:5432/bling_db

JWT_SECRET_KEY=troque_por_secrets.token_hex(32)
JWT_ALGORITHM=HS256
JWT_EXPIRE_MINUTES=480

BLING_CLIENT_ID=seu_client_id
BLING_CLIENT_SECRET=seu_client_secret
BLING_REDIRECT_URI=http://localhost:8000/auth/bling/callback

SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=seu@email.com
SMTP_PASSWORD=senha_de_app

Gerar a chave:

import secrets; print(secrets.token_hex(32))

Carregamento robusto do .env

Seu auth.py resolve o caminho de forma absoluta — funciona independentemente de onde o uvicorn foi iniciado:

base_dir = Path(__file__).resolve().parent.parent
if (base_dir / ".env").exists():
    load_dotenv(base_dir / ".env")
else:
    load_dotenv(base_dir.parent / ".env")
